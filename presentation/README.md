## How to Conduct an Executive Showcase

### Step 1: The Narrative
Start by walking through the **Executive Narrative**. Focus on the shift from manual, siloed operations to an orchestrated, AI-native cognitive infrastructure.

### Step 2: The Command Center
Launch the **Executive Command Center** (`streamlit run ui/main.py`). Demonstrate real-time metrics, treasury performance, and the cognitive event stream.

### Step 3: The Operational Demo
Execute the **Institutional Demo Workflow** (`python demo/run_demo.py`). Watch as the command center updates in real-time with AML escalations and fraud prevention events.

### Step 4: The Technical Validation
Present the **Technical Topology**. Explain the security hardening (JWT/RBAC), the distributed agent coordination, and the adaptive ontology foundation.

### Step 5: The Strategic Q&A
Conclude with the **AI Positioning Strategy**, emphasizing our commitment to explainability, semantic integrity, and human-in-the-loop governance.
