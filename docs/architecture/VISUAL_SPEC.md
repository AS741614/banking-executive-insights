## 4. Technical Quality Standards

- **Resolution**: Minimum 1920x1080 (2K preferred).
- **Format**: PNG (Lossless).
- **Browser**: Chrome or Arc (Clean profile, no extensions visible).
- **Theme**: Institutional Dark (#050816) strictly enforced.
- **State**: No mock theater; all data must be simulated through the real ECOS kernel.
